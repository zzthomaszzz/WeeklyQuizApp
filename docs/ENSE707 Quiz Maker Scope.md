# Project Scope

# Project Overview

The project “Quiz Maker ”aims to develop a  Web-based Weekly Quiz Management System that helps students reinforce their understanding of lectures. Nowadays, a lot of university students skipping their lectures and rely solely on lecture slides for learning. Instead of reading slides, students need to complete weekly quizzes made by lecturers to assess their understanding of the lecture content. The system will demonstrate how software quality can be improved through well-defined requirements, effective design, comprehensive testing, and quality assurance practices.

# In Scope

The prototype will include a complete workflow for both lecturers and students. Lecturers will be able to securely log in and create, manage courses, create and publish weekly quizzes based on lecture slides. Also edit quiz questions and review students' performance. Students will be able to securely log in, access available quizzes, complete weekly assessments, receive scores and feedback, review previous quiz attempts, and monitor their learning progress throughout the semester. The system will implement role-based access control, input validation, secure authentication, search and filtering of quizzes, progress reporting, and basic learning analytics. Sample data will be included so that both normal and exceptional scenarios, such as invalid logins, incomplete quiz submissions, duplicate submissions, unpublished quizzes, and invalid input, can be demonstrated during testing.

### **User Management**

Secure login for lecturers and students.   
Role-based access control(Lecturer and Students)

### **Lecturer Module**

Able to create and manage courses  
Create weekly quizzes  
Add , edit and delete the questions(multiple-choice in quiz)  
Publish or unpublish quizzes  
View student submission and quiz results  
View basic class performance statistics.

### **Student Module**

View available weekly quizzes  
Complete quizzes online.  
Submit quiz answers.  
Receive scores and feedback after submission  
Review previous quiz attempts and scores.  
View personal learning progress across different weeks.

### **System Quality Features**

Input validation to prevent invalid quiz data  
Secure authentication and authorised access  
Responsive web interface for desktop browse  
Storage of quiz submission and results

### **Software Quality Assurance Activities**

Functional and non-functional requirements specification  
Unit, user acceptance testing  
AI-assisted development using GitHub Copilot  
GitHub repository with version history and team contributions

# Out of Scope

To ensure the project remains achievable within one semester, the following features are excluded:  
Mobile version applications  
AI-generated quiz questions  
Push notifications like email reminders or SMS services  
Video conferencing or live lecture streaming
